# T6 · Autonomia

Esforço: 14–20 h · Badge: Autonomia

## Objetivo mensurável

Operar um agente agendado com limites, aprovação humana e evals de comportamento.

## Vitória de abertura

Um agente agendado concluindo uma tarefa sem o aluno presente.
