# Custos das ferramentas da formação

Consulta: outubro de 2026. Valores em dólar. Revisar antes de publicar: preços mudam com frequência.

| Ferramenta | Quando o aluno precisa | Plano | Custo |
| --- | --- | --- | --- |
| Claude | Desde a T0 | Pro | US$ 20/mês (cerca de US$ 17/mês no plano anual). O Claude Code não está disponível no plano gratuito |
| Claude (opcional) | Uso intenso de Claude Code | Max | US$ 100/mês (5x o uso do Pro) ou US$ 200/mês (20x) |

| Supabase | Desde a T2 | Free; Pro no lançamento | Free: US$ 0 (banco de 500 MB, 50 mil usuários ativos/mês, pausa após 1 semana sem uso). Pro: US$ 25/mês |
| Vercel | Desde a T2 | Hobby; Pro se comercial | Hobby: US$ 0, só para uso pessoal e não comercial. Pro: US$ 20/usuário/mês + uso |
| API Anthropic | Desde a T4 | Pagamento por uso | Calculado pelo aluno na lição D5 da T4 |
| n8n | T5 | Self-hosted ou Cloud | Community (self-hosted): gratuito + servidor de US$ 3 a 7/mês. Cloud: a partir de US$ 20 a 24/mês |
| Usuários sintéticos | T1 e T2b | Pacote avulso | A confirmar após o teste do aluno zero |
