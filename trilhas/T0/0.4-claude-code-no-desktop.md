# 0.4 · Seu primeiro utilitário construído pelo Claude (Claude Code no Desktop)

- **Trilha:** T0 · Pré-voo
- **Tempo:** 90 min
- **Evidência:** checklist + utilitário funcionando

## Por quê

Até aqui, o Claude entregou respostas e arquivos avulsos. O Claude Code vai além: cria e altera arquivos numa pasta do seu computador.

É com ele que você constrói o produto a partir da T2. Você decide o quê e o porquê; o Claude Code executa o como.

Aqui você monta o ambiente e vê o ciclo completo num utilitário pequeno e útil.

## Demonstração

Exemplo: um profissional sênior quer saber quanto custam as reuniões recorrentes da equipe.

1. Crie a pasta `calculadora-reunioes` fora do OneDrive.
2. No Claude Desktop, abra a aba de código e selecione essa pasta. [VERIFICAR NA INTERFACE]
3. Peça: "Inicie um repositório git nesta pasta."
4. Peça: "Crie uma página HTML que calcula o custo de uma reunião: participantes, valor-hora médio e duração. Tudo num único arquivo, sem internet."
5. Aprove a criação do arquivo quando o Claude Code pedir. [VERIFICAR NA INTERFACE]
6. Abra o arquivo com duplo clique e teste: 6 pessoas, R$ 200/hora, 1 hora.
7. Confira a conta à mão: 6 × 200 × 1 = R$ 1.200.
8. Peça um ajuste: "Acrescente o número de reuniões por mês e mostre o custo mensal."
9. Recarregue a página e confira o ajuste.

## Prática

1. Cumpra o checklist de setup (Referência).
2. Crie a pasta do seu repositório pessoal, fora do OneDrive.
3. Abra a pasta na aba de código do Claude Desktop. [VERIFICAR NA INTERFACE]
4. Peça para iniciar um repositório git na pasta.
5. Escolha um utilitário pequeno que resolva um incômodo real do seu trabalho.
6. Peça o utilitário como página HTML num único arquivo, sem internet.
7. Teste com um caso real e confira o resultado à mão.
8. Peça pelo menos um ajuste e teste de novo.

## Checagem

Entrega: checklist de setup completo + utilitário funcionando (arquivo + print da tela).

## Referência

**Checklist de setup**

- [ ] Conta no Claude com acesso ao Claude Code
- [ ] Contas no GitHub, Supabase e Vercel
- [ ] Git instalado (exigido pelo Claude Code); Node instalado (necessário a partir da T2)
- [ ] Editor instalado (para leitura)
- [ ] Claude Desktop instalado, com a aba de código funcionando
- [ ] Teste final: o Claude Code, no Desktop, criou um arquivo na pasta do repositório

**Pedido de utilitário:** problema + entradas + saída + "num único arquivo HTML, sem internet"

**Erro comum (Tutor HIC):** repositório dentro do OneDrive gera erros de `index.lock` ou arquivos duplicados. Solução: pausar a sincronização durante o trabalho ou manter o repositório fora do OneDrive.
