# 0.4 · Seu primeiro utilitário construído pelo Claude (Claude Code no Desktop)

- **Trilha:** T0 · Pré-voo
- **Tempo:** 90 min
- **Evidência:** checklist + utilitário funcionando

## Por quê

Até aqui, o Claude entregou respostas e arquivos avulsos. O Claude Code vai além: cria e altera arquivos numa pasta do seu computador.

É com ele que você constrói o produto a partir da T2. Você decide o quê e o porquê; o Claude Code executa o como.

Aqui você monta o ambiente e vê o ciclo completo num utilitário pequeno e útil.

## Demonstração

Exemplo: um profissional sênior quer saber quanto custam as reuniões recorrentes da equipe.

1. Crie a pasta `calculadora-reunioes` fora do OneDrive.
2. Abra a pasta no modo de código do Claude Desktop (veja "Abrir uma pasta", na Referência).
3. Deixe o modo de permissão em **Manual**: o Claude Code pede aprovação antes de cada mudança.
4. Peça: "Inicie um repositório git nesta pasta." O git guarda versões da pasta; você vai usá-lo na 0.5.
5. Peça: "Crie uma página HTML (abre no navegador) que calcula o custo de uma reunião: participantes, valor-hora médio e duração. Tudo num único arquivo, sem internet."
6. Confira a mudança proposta e aprove a criação do arquivo.
7. Abra o arquivo com duplo clique e teste: 6 pessoas, R$ 200/hora, 1 hora.
8. Confira a conta à mão: 6 × 200 × 1 = R$ 1.200.
9. Peça um ajuste: "Acrescente o número de reuniões por mês e mostre o custo mensal."
10. Recarregue a página e confira o ajuste.

[Guia oficial: começar com o Claude Code no app desktop (em inglês)](https://code.claude.com/docs/en/desktop-quickstart)

## Prática

1. Monte o ambiente com o checklist de setup, no fim desta lição. Ele lista as contas, os programas e um teste final.
2. Marque cada item à medida que concluir. O checklist preenchido faz parte da entrega.
3. Crie a pasta do seu projeto pessoal, fora do OneDrive.
4. Abra a pasta no modo de código, em **Manual** (veja "Abrir uma pasta", na Referência).
5. Peça para iniciar um repositório git na pasta. A pasta passa a ser seu repositório.
6. Escolha um utilitário pequeno para um incômodo real do trabalho (veja "Escolha do utilitário", na Referência).
7. Peça o utilitário como página HTML num único arquivo, sem internet.
8. Teste com um caso real e confira o resultado à mão.
9. Peça pelo menos um ajuste e teste de novo.

## Checagem

Entrega: checklist de setup completo + utilitário funcionando (arquivo + print da tela).

## Referência

**Checklist de setup**

- [ ] Conta no Claude com acesso ao Claude Code
- [ ] Conta no GitHub (guarda versões na nuvem)
- [ ] Contas no Supabase (banco de dados) e na Vercel (publica apps), usadas a partir da T2
- [ ] Git instalado (guarda versões; exigido pelo Claude Code); Node instalado (roda programas; necessário a partir da T2)
- [ ] Editor instalado (para ler os arquivos gerados) [LACUNA: editor de referência não definido na ementa]
- [ ] Claude Desktop instalado, com o modo de código (ícone **</>**) funcionando
- [ ] Teste final: o Claude Code, no Desktop, criou um arquivo na pasta do repositório

**Termos**

- Git: guarda versões de uma pasta e permite voltar a qualquer uma
- Repositório: pasta cujas versões o git guarda
- HTML: formato de página que abre no navegador

**Abrir uma pasta**

1. No Claude Desktop, clique no ícone de código (**</>**), no canto superior esquerdo.
2. Na barra lateral, clique em **Criar** para abrir uma sessão nova.
3. No painel à direita, em **Ambiente**, confirme **Este computador**.
4. Logo abaixo, clique na linha da pasta e selecione a pasta do projeto. [VERIFICAR NA INTERFACE: nome da opção que abre a pasta]
5. Abaixo da caixa de mensagem, à direita, abra o seletor de modo e escolha **Manual** ("Sempre perguntar antes de fazer alterações").

| Modo | O que faz |
| --- | --- |
| Automático | O Claude decide quando pedir permissão |
| Manual | Pergunta antes de cada alteração; use enquanto aprende |
| Aceitar edições | Aplica edições de arquivo sem perguntar |
| Plano | Cria um plano antes de alterar qualquer coisa |
| Ignorar permissões | Aceita tudo sem perguntar; não use |

- Nomes conforme o app em português; o guia oficial (link na Demonstração) está em inglês e mostra outra disposição dos controles

**Escolha do utilitário**

- Boa escolha: tarefa semanal, com regra clara, hoje feita com conta ou cópia manual
- Teste: a regra cabe em duas frases
- Evitar por enquanto: login, banco de dados ou internet (ficam para a T2)
- Exemplos:
  - Prazo em dias úteis: soma N dias úteis a uma data, pulando fins de semana e feriados listados
  - Gerador de e-mail padrão: campos (cliente, data, valor) que montam o texto para copiar
  - Matriz de decisão: opções, critérios e pesos que geram nota final e ranking

**Pedido de utilitário:** problema + entradas + saída + "num único arquivo HTML, sem internet"

**Erro comum (Tutor HIC):** repositório dentro do OneDrive gera erros de `index.lock` ou arquivos duplicados. Solução: pausar a sincronização durante o trabalho ou manter o repositório fora do OneDrive.
