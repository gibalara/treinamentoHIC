# T0 · Pré-voo

Esforço: 6–8 h · Badge: Pré-voo

## Objetivo mensurável

Usar conectores e skills para gerar um entregável real e operar o Claude Code num repositório próprio.

## Vitória de abertura

Claude conectado ao próprio e-mail, agenda ou drive, gerando um entregável real com skills oficiais.

## Lições

- 0.1 · Claude trabalhando no seu e-mail, agenda e drive (conectores)
- 0.2 · Um entregável pronto a partir dos seus dados (skills oficiais)
- 0.3 · Seu plano de jornada: o que construir, quanto custa e em que ritmo
- 0.4 · Seu primeiro utilitário construído pelo Claude (Claude Code no Desktop)
- 0.5 · Salvar, voltar versões e entender o código gerado (git e leitura de código)
- 0.6 · Pedidos que viram especificação (engenharia de contexto)
- 0.7 · Uma tarefa recorrente automatizada (Claude Cowork)
- 0.8 · Ajuda quando você travar (Tutor HIC)
