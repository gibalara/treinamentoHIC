## Pasta vazia no GitHub

- **Erro:** não consigo criar uma pasta vazia no GitHub pela web.
- **Causa:** o GitHub não guarda pastas vazias.
- **Solução:** Add file > Create new file, digitar "nome-da-pasta/nome-do-arquivo.md". A pasta é criada junto com o arquivo.
- **Lição relacionada:** 0.5
