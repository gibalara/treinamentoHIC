## Pasta vazia no GitHub

- **Erro:** não consigo criar uma pasta vazia no GitHub pela web.
- **Causa:** o GitHub não guarda pastas vazias.
- **Solução:** Add file > Create new file, digitar "nome-da-pasta/nome-do-arquivo.md". A pasta é criada junto com o arquivo.
- **Lição relacionada:** 0.5

## Caminho com espaços no PowerShell

- **Erro:** "Não é possível localizar um parâmetro posicional" ao usar `cd` no PowerShell.
- **Causa:** espaços no caminho.
- **Solução:** colocar o caminho entre aspas, ou usar o Claude Code no Claude Desktop.
- **Lição relacionada:** 0.5

## Repositório dentro do OneDrive

- **Erro:** erros de `index.lock` ou arquivos duplicados no repositório dentro do OneDrive.
- **Causa:** sincronização do OneDrive.
- **Solução:** pausar a sincronização durante o trabalho, ou manter o repositório fora do OneDrive.
- **Lição relacionada:** 0.4
